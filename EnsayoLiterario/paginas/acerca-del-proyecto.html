Acerca del proyecto

Para realizar este proyecto primero seleccioné dos obras literarias que serían la base del trabajo: El principito, de Antoine de Saint-Exupéry, y Aura, de Carlos Fuentes. Después de elegirlas, comencé a organizar la información que quería presentar sobre cada una y a pensar en la manera de integrarla dentro de una página web.

Posteriormente, comencé a desarrollar el sitio utilizando Dreamweaver. Primero elaboré la estructura principal, agregando el encabezado, el menú de navegación y la página de inicio. Después incorporé un banner relacionado con las obras y un carrusel de imágenes para presentar de una manera más visual los libros seleccionados.

Una vez terminada la estructura inicial, comencé a crear las páginas individuales de cada obra. En ellas agregué las portadas y las introducciones correspondientes. Algunas partes, como los videos y las conclusiones, quedaron planeadas para incorporarse posteriormente.

Durante el proceso fui realizando diferentes ajustes al diseño, al tamaño de las imágenes, a la navegación y a la organización de los elementos. De esta manera, el proyecto no solo me permitió trabajar con las obras literarias, sino también aplicar los conocimientos de desarrollo y diseño de páginas web aprendidos durante las clases.
